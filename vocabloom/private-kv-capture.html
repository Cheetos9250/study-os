VocaBLoom · สำรอง PROGRESS KV จาก Cloudflare

สำหรับตรวจข้อมูลต้นทางก่อนย้ายระบบ · ใช้กับ Worker study-api เท่านั้น

ไม่มีการเข้าถึง Cloudflare ผ่านหน้านี้ — คุณเปิดค่าจริงจาก Cloudflare Dashboard เอง แล้วเลือกไฟล์ที่ดาวน์โหลดลงในช่องของวิชานั้น หรือวางข้อความ JSON โดยตรง หน้านี้ถูกกำหนดให้เชื่อมต่อเครือข่ายไม่ได้ และไม่มีระบบเก็บข้อมูลหรือรหัส
ห้ามใช้ข้อมูลจากหน้า VocaBLoom Cloud snapshot มาแทนค่า KV จริง เพราะ `{"updated":0}` อาจเป็นคำตอบที่ Worker สร้างขึ้น ไม่ใช่ค่าที่เก็บอยู่ใน KV

เปิด Cloudflare → Workers & Pages → study-api → Settings → Bindings → PROGRESS แล้วเปิด KV Namespace ที่เชื่อมอยู่ จากนั้นตรวจแต่ละคีย์ใน KV Pairs แบบอ่านอย่างเดียว

ไฟล์สำรองมีข้อมูลการเรียนจริง เก็บใน Google Drive ส่วนตัว อย่าอัปโหลดขึ้น GitHub หรือแชร์สาธารณะ

ผลการตรวจ

ยังไม่ได้ตรวจครบทั้ง 5 คีย์

สถานะนี้เป็นเพียงการรวบรวมจาก Dashboard ไม่ใช่หลักฐานการสำรองทั้ง Namespace แบบ atomic และยังไม่อนุญาต Deploy หรือ Restore ระบบจริง
