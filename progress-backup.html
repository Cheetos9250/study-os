Back up your learning progress

For single-iPad learners · Save a private copy to Files or iCloud Drive

1. Download a backup

Back up local quiz and flashcard progress for the five legacy courses and VocaBloom. Only data saved by this website in this browser context is included.

Sync keys, passwords, and unrelated browser data are excluded. Nothing is sent to a server.

2. Check your downloaded file

Select the JSON file you just saved to check its structure, date, and number of saved data sets. This does not change your progress.

Important limitations

This is a read-only backup, not a restore tool. It does not overwrite your existing progress.

This backup excludes Study Planner records in IndexedDB and records stored only in Cloudflare or Notion. Export those separately when their tools are available.

Before clearing Safari, changing devices, or upgrading, save and check the file in Files/iCloud Drive. Do not delete your original progress. If you use an iPad Home Screen app, launch this page from that same app: its storage may be separate from Safari.
