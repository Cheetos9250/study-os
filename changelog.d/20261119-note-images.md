- Notes take pictures: paste an image into a note or tap **Add image** (quiz notes, Practice notebook, Lessons notes). Pictures are shrunk to 1400 px JPEG, kept on the device in IndexedDB and uploaded to the sync Worker's new `/img/<id>` store (one immutable entry per picture, id checked against its SHA-256), and other devices download them when the note needs them. The note's picture list (`imgs`) is backed up and syncs with the note; every note writer keeps it. The image store needs one more run of the Worker deploy workflow.
