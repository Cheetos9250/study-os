What the teacher said about the final

  • The final asks you to build this dashboard, especially the Expense table with % of Total.
  • The data may be accounting data (e.g. from adjusting entries). Use the same steps but think about what the report is about: if it asks for Asset, filter and label Asset instead of Income.
  • A PivotTable is built from the column headers. Each header becomes a field. Keep the data as an active Excel table (do not use Convert to Range).
  • Make it look professional: tables lined up, a clear title, and headline numbers. "Your manager wants to read this report."

Common mistakes and fixes

  • New rows do not show in the report: paste them directly under the table so the table grows, then Data → Refresh All.
  • Slicer changes only one table: right-click the slicer → Report Connections → tick the other PivotTables.
  • Negative bars are red or point the wrong way: Manage Rules → Edit Rule → Negative Value and Axis → fill colour pink, then set Bar Direction: Right-to-Left.
  • Rule colours only part of the table: in Edit Rule choose All cells showing "Sum of …" values for "Subcategory" (or "Category"), not Selected cells.
  • Group selects the wrong units: in the Group box hold Ctrl (⌘ on Mac) while clicking, so you can untick Days and keep Months + Years.
  • Group is greyed out: some Date cells are text or blank. Fix them to real dates, then refresh.
  • Month names show in Thai: Excel takes group names from the computer's region format. Set the region format to English (Windows: Settings → Time & language → Region; Mac: System Settings → General → Language & Region), reopen Excel and group again.
  • Columns jump in width after refresh: PivotTable Options → untick Autofit column widths on update.
  • ;;; made the numbers vanish: that is intended for the bar column. The values are still there (formula bar shows them).

Shortcuts used
